# Security Policy / Política de Segurança

## Versões suportadas

| Versão | Suporte |
|---|---|
| 1.0.x | ✅ |

## Relatando uma vulnerabilidade

**Não abra uma issue pública.** Use *Security → Report a vulnerability* (GitHub Private Vulnerability Reporting) neste repositório, descrevendo: versão, sistema (Termux/Windows/Linux), passos para reproduzir e impacto. Responderemos em até 7 dias e publicaremos a correção com crédito, se desejar.

Escopo de interesse: execução de comandos não intencional, vazamento de credenciais (logs, saída, arquivos), contorno das confirmações de operações arriscadas, falhas que causem perda de dados locais ou remotos.

Detalhes de como a ferramenta protege seus dados: [docs/SECURITY.md](docs/SECURITY.md).
